# ANTI-NATIONALS
*A satire.*

A Godot 4 prototype for a single-player political satire game. This is a greybox starter, not a complete open world.

## Current prototype
- Third-person movement and camera
- Small university courtyard with placeholder buildings
- NPC crowd placeholders
- An argument that starts without the player
- Player actions: record, calm, provoke, walk away
- Basic journal, reputation, clock, and save/load
- Desktop keyboard controls; mobile touch controls are a later milestone

## Run it
1. Install Godot 4.x: https://godotengine.org/download
2. Extract this ZIP.
3. Open Godot and import `project.godot`.
4. Press F6 to run the main scene, or F5 if the project main scene is configured.

## Controls
WASD move, mouse look, Shift sprint, E interact, Esc release mouse. Use on-screen buttons for event actions and saving/loading.

## Scope
This first slice tests the core gameplay loop. Vehicles, multiple districts, advanced factions, a 50+ NPC crowd, final art, voice acting and polished Android controls are future milestones.
